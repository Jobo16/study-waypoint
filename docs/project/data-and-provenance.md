# 留学项目采集字段与溯源

首期以本科生为主要查询对象，覆盖交换、访学和国际暑校，包括国内高校的选派公告和国内外高校的招收公告。申请人可以用采集结果核对资格、查看当前可走的申请路径，并评估项目所需的时间和预算。以「主办学校 → 项目 → 批次 → 申请路径」组织记录。同一批次有独立的提名和个人申请路径时，各自保留资格、窗口和费用。暑校若有多个场次，记录各场次的项目时间和适用条件。

## 采集字段

| 类别 | 首期优先抓取 | 有官方信息时补充 |
| --- | --- | --- |
| 项目与批次 | 主办学校和院系、项目举办国家或地区、官方项目名、类型、学期或届次、项目起止时间或官方时间范围 | 场次、校区、线下或线上形式 |
| 资格与申请路径 | 个人申请或学校提名、适用学生身份和学校范围，官方明确的国籍、就读地、院系、年级、语言、成绩或专业限制 | 语言豁免、合作院校清单链接 |
| 申请与截止 | 申请开始、截止和状态，官方申请入口或获取方式，提名路径各阶段的日期 | 材料清单、录取通知时间、接受录取和缴费期限、项目办公室联系方式 |
| 费用与资助 | 学费或项目费、必缴申请费及杂费，金额、币种、计费单位和适用对象。官网未公布时保留该状态 | 奖学金和费用减免、住宿费、退款规则 |
| 学习内容 | 可选学科或课程目录链接、学分及成绩单说明，官网有明确课程限制时记录 | 授课语言、课时、选课与考核规则、学分转换说明 |
| 行前安排 | 记录影响决策的公开信息及官方说明入口，例如是否提供住宿和是否有单独的签证或保险说明 | 住宿申请截止、行前指南、报到日期、合同或付款条款链接 |

## 发布方、举办地与适用人群

- **发布方**跟着来源走。记录发布公告的学校或院系及所在国家或地区，并标明公告用于主办校招收还是派出校选拔。一个项目可以关联两方来源。
- **主办方和举办地**跟着项目走。记录负责接收学生的学校、联合主办方（如有）和实际举办地。用国家或地区字段支持用户按国内高校、国外高校或目的地查询。
- **适用人群**跟着申请路径走。记录限指定学校或学院、限合作院校，或接受符合条件的外校申请，并核对高中生、本科生、研究生等学生身份，以及年级、专业、就读地区和国籍限制。国籍和就读地区分别保存。官网有不同人群的报名入口时，分别保留报名方式和限制。申请人信息或官方条件不足时，标记资格待核实。

| 官方样例 | 如何记录 |
| --- | --- |
| 华东师大经管学院选派学生赴 NUS | 发布方是华东师大经管学院，接收方是 NUS，举办地是新加坡。校内选拔面向该学院大二、大三全日制本科生，校内截止和提名后的 NUS 申请分别关联两校来源。 [华东师大公告](https://sem.ecnu.edu.cn/c8/a9/c43558a772265/page.htm) · [NUS 入境交换](https://www.nus.edu.sg/gro/global-programmes/student-exchange/incoming-exchangers) |
| 复旦 2026 全球公共政策国际暑校 | 复旦发布并在国内举办，主要面向海内外高校在读本科生。报名须知接受不同国籍，但为中国学生和非中国籍学生提供了不同的申请入口。 [复旦报名须知](https://igpp.fudan.edu.cn/summer_school/43737/list.htm) |
| NTU 学期交换 | NTU 发布并在新加坡接收学生，申请人需来自合作院校并获得所在学校提名。可以据接收方项目页核对资格，再从学生所在学校核对校内选派。 [NTU GEM Trailblazer](https://www.ntu.edu.sg/education/student-exchanges/exchange-programmes/inbound-programmes) |

两校公告确认指向同一项目和批次时，挂到同一条项目记录下。每所派出学校的选拔条件、名额、校内截止和报名入口仍挂在该校的申请路径上。

## 容易混淆的口径

- **三种截止各按阶段记录。** 本校内部报名截止由学生所在学校公布。主办校接收提名的截止和学生提交申请的截止分别从主办校来源核验。NTU 的交换项目把后两者列为独立窗口，并说明提名通过后如何获取申请链接。 [NTU GEM Trailblazer](https://www.ntu.edu.sg/education/student-exchanges/exchange-programmes/inbound-programmes)
- **申请路径与收费方式分别提取。** 在 NUS 的 Non-Graduating Coursework 中，付费的 Non-Exchange 路径也要求由本校选派。合作院校、学生类别、院系等限制应和对应路径一起保存。 [NUS Non-Graduating Coursework](https://nus.edu.sg/registrar/prospective-students/non-graduating/coursework)
- **申请状态与个人资格分别判断。** 「开放、未开放、已截止、待核实」描述指定批次和路径在核验日的状态。个人是否能申请还取决于本校提名、适用人群等条件。有明确的名额已满或提前关闭公告时一并记录。
- **保留日期精度和缺失原因。** 官方只写月份或日期时按其精度保存，时区和具体时间以可核实的资料为准。「未查到」「校方尚未公布」「不适用」按实际情况记录。项目举办时间、申请截止和优惠截止分别保存。SMU 暑校的 2027 年申请窗口和早鸟期限就是两个独立字段。 [SMU 暑校项目页](https://geo.smu.edu.sg/study-in-smu/global-summer-programme) · [SMU 暑校 FAQ](https://geo.smu.edu.sg/study-in-smu/global-summer-programme/faq)

## 字段怎么核验

项目身份、申请状态、日期、资格、申请入口和必缴费用等字段都要能回到具体证据。同一段原文可供多个字段引用。

| 记录 | 保留内容 |
| --- | --- |
| 来源页面 | 实际读取的 URL、页面或文档标题、发布学校或院系、来源类型（项目页、当期公告、FAQ、PDF 等）、发现它的上一级入口。发生重定向时记录最终 URL |
| 字段证据 | 该来源适用的批次和申请路径、支持判断的原文短摘、网页小标题或锚点、PDF 页码和表格或章节名 |
| 核验与判断 | 核验时间、读取方式（网页正文、PDF、浏览器或人工复核）。字段由其他信息推导时，记录所用证据和规则，例如按当期申请截止日计算状态 |

优先找负责该字段的当期官方来源。申请窗口通常查当期公告或官方 FAQ，费用查官方价目或项目页，本校内部报名查本校国际处。通用 FAQ 和往届 PDF 可以提供检索线索。存在同批次官方冲突时保留双方出处并标记待核实。页面无法读取时记录访问情况，保留上次验证的值和时间，供人工检查。

SMU 访学页的春季 2027 区块同时显示申请窗口和申请按钮。证据可以定位到该区块下的 `APPLICATION PERIOD`，保存截止日 `25 SEP 2026`，再以核验日期 2026 年 11 月 25 日计算为「已截止」。复核时打开来源，按学期标题和小标题找到对应段落。 [SMU 访学项目页](https://geo.smu.edu.sg/study-in-smu/visiting-student-programme)

## 下次从哪里查

项目记录挂上字段所用的来源，来源再指回发现它的栏目或项目页。至少能从「学校 → 项目 → 批次 → 字段」直接找到上次核验的精确位置，也能从学校的国际处、学院或招生栏目查新项目和新批次。学校、项目、批次和路径用稳定标识关联，URL 作为可更新的来源地址。

1. **更新已有字段时直达上次来源。** 查日期回申请公告或 FAQ，查费用回价目页，查招收资格回主办校项目条款，查校内资格回派出校或对应院系的选派公告。重读上次对应的段落、表格或 PDF 页，并确认它仍适用于目标批次。判断新的「现在是否开放」时重算窗口状态，当前日期变化和网页内容变化分别记录。
2. **原链接失效时沿父入口找。** 先读原地址的跳转目标，再回到记录的项目页、类别栏目或附件列表。用原项目名、届次和字段关键词做官网站内或域名定向搜索。官网把同一 URL 更新为下一届时，新建下一届记录并保留上一届证据。
3. **找新增项目时从已知栏目开始。** 复扫各校已有的入口和近期公告，展开新出现的项目、场次和附件。已有入口检查完仍有缺口时，再扩大域名定向搜索。
4. **更新时只替换核实过的值。** 写下旧值、新值、核验时间和对应证据。网页挪址更新来源关系，项目记录继续沿用。来源失效后仍无法核实，或同批次证据存在冲突时，标记有关字段为待核实，旧值及原文仍可回查。
