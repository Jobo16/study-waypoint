# AI 爬虫

让 Codex 这类 Agent 从公开网站持续收集有时效的数据。用户给出来源范围和筛选条件，Agent 发现相关页面、核实关键字段，输出可追溯的结构化结果。页面地址和内容会变，工作流以学校等来源实体和项目批次为线索，保留每次查到的证据。

首轮用同样的采集口径和时间预算，验证给 Codex 加上站点发现和抓取工具后，能否减少漏项、误判或调查耗时。

## 首期场景

以新加坡教育部名录中的六所自治大学为首轮覆盖样本，寻找面向外校本科生的入境交换、访学和暑校项目。加上国内高校的出境选派和国内举办的国际暑校样本，验证不同申请人群和路径。每次运行指定学校范围、目标批次和核验日期，并可按申请人的学校、年级和适用的国籍条件筛选。 [新加坡教育部名录](https://www.moe.gov.sg/-/media/files/post-secondary/post-secondary-school-booklet-2021.pdf) · [华东师大选派公告](https://sem.ecnu.edu.cn/c8/a9/c43558a772265/page.htm) · [复旦国际暑校报名须知](https://igpp.fudan.edu.cn/summer_school/43737/list.htm)

用户可以据此查看当前可申请的项目、核对是否需要学校提名，并追溯逐校检查的来源。

## 采集流程

1. **逐校找入口。** 从学校名单和官网域名出发，按校搜索国际处、招生处和学院的相关栏目。查主办校的 `incoming exchange`、`visiting student`、`summer programme` 等入口，也查申请人所在学校的海外学习、选派公告，以及国内高校发布的国际暑校等报名入口。沿栏目、站点地图和正文链接找到项目页、FAQ、公告及 PDF。
2. **读取来源。** 普通网页先用 HTTP 读取正文和链接。页面依赖前端渲染、批量读取费时，或入口线索不足时，试用 Firecrawl 的 `scrape`、`map` 或限定范围的 `crawl`。PDF 尽量保留页码，网页保留对应段落。 [Firecrawl MCP](https://github.com/firecrawl/firecrawl-mcp-server)
3. **核对申请批次。** Codex 把申请日期、对象、提名要求和报名入口对齐到同一批次。用官方来源中的申请窗口判断状态，遇到日期缺失、适用对象不明确或官方来源冲突时标为「待核实」。
4. **交付与复查。** 保存项目结果和逐校检查记录。下一轮回访已知来源以发现资格或截止日变化，再重查入口以发现新批次和迁移的页面。已知链接失效时，从该校入口重新发现，并用学校、项目、批次及申请路径匹配已有记录。

Codex 负责搜索策略、页面选择、字段提取和证据核验。网页工具负责返回 URL、正文和附件。首轮用一次手工复跑验证更新流程，频率在试点后按数据变化决定。

## 输出

**项目表**按项目批次和申请路径记录。分别保留发布学校、主办学校、项目举办地和适用人群，再采集申请窗口、入口、费用、学习内容及影响决策的行前安排。关键字段引用到官方网页段落或 PDF 页码，并记录适用批次和核验时间。详细字段、验证规则和就近复查顺序见 [留学项目采集字段与溯源](data-and-provenance.md)。

**逐校检查记录**保留已查的官方栏目、发现的链接、读取失败的页面和仍需补查的线索。每所学校都有记录，包括查过但未发现符合条件项目的学校。这样能汇报学校检查进度，也能回到具体来源核对漏项。

## 首轮对照与验收

用同一学校名单、项目范围、核验日期和时间预算跑两组。A 组用 Codex 原生搜索加 HTTP，B 组在同一流程中加 Firecrawl。先人工逐校核一份参考清单，两组额外找到的项目经官网确认后补入参考清单，再统一计分。

- **覆盖**记录查过几所学校、找到多少参考项目，以及漏在哪个官网入口或申请批次。
- **准确度**统计适用人群、申请状态、日期和提名要求的错误，单独记下把校内名额误判成对外开放，或把已截止、未开放误判成开放的条目。
- **成本**记录总耗时、人工补查时间和工具调用量。只有新增工具能补到有效项目、改善判断或节省时间时，才值得接入常用流程。
- **复查**抽查截止日、提名要求和费用，确认能从字段直接定位到官方证据。用留存样例复跑，验证同批次改期和链接迁移能更新到原记录，并保留上次核验的值和来源。

## 已验证的样例

- SMU 国际交流中心首页用普通 HTTP 就能发现交换、访学和暑校入口。2027 年春季访学页仍显示 `Apply Now`，申请窗口实际已在 2026 年 9 月 25 日结束。 [SMU 访学项目](https://geo.smu.edu.sg/study-in-smu/visiting-student-programme)
- NUS 理学院暑校的 2027 项目区写明 2027 年 2 月开始申请，搜索仍会带出旧内容和 2026 年申请指南。 [NUS 暑校项目](https://www.science.nus.edu.sg/undergraduates/study-abroad-programmes/incoming/gssp/) · [2026 年申请指南](https://www.science.nus.edu.sg/wp-content/uploads/2026/01/GSSP-NG-online-application-guide-1.pdf)
- 当前网络下，Firecrawl 免密钥搜索和抓取请求返回 403，`map` 返回 401 并要求 API Key。使用带凭证的连接实测后，再评估它的覆盖和耗时。 [Firecrawl 免密钥说明](https://docs.firecrawl.dev/mcp-server/keyless)
